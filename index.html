// 01 — about

Professional summary

I'm a cybersecurity professional specializing in application security, VAPT and DevSecOps. My day-to-day is finding the vulnerabilities that matter — the ones an attacker would actually use — and wiring security checks directly into the pipelines teams already ship through, rather than bolting them on afterward.

I work across the stack: manual and tool-assisted penetration testing on web applications and network infrastructure, static and dependency scanning inside CI/CD, container and Kubernetes hardening, and real-time monitoring once code reaches production. My foundation is a PG Diploma in IT Infrastructure & Systems Security from CDAC Pune, and I'm currently pursuing CEH Master on top of hands-on practice via TryHackMe, Hack The Box and Bugcrowd.
